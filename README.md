# Knerdly

> A modern, responsive web application built to provide a clean and accessible platform for discovering and engaging with knowledge.

🌐 **Live Demo:** [knerdly.vercel.app](https://knerdly.vercel.app)

---

## 📌 About

**Knerdly** is a web application developed with a focus on modern interface design, responsive usability, and a smooth user experience across devices.

The project is built as a production-oriented application using a modern React-based stack and a cloud backend.

## ✨ Highlights

* 📱 Mobile-first responsive interface

* 🔐 User authentication and application flows
* 🗄️ Cloud-backed data management

* 📐 Responsive layouts for desktop and mobile devices

## 💻 Local Development

Clone the repository:

```bash
git clone https://github.com/hasan2bd/knerdly.git
```

Navigate into the project:

```bash
cd knerdly
```

Install dependencies:

```bash
npm install
```

Create your environment configuration according to the variables required by the project.

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

## 🔐 Environment Variables

The application uses environment variables for configuration and external services.

Create a `.env.local` file and add the required values for your local environment.

**Never commit sensitive credentials, API keys, passwords, or secret environment variables to GitHub.**
